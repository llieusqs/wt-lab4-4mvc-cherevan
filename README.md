# WT-4 — ASP.NET Core MVC

Лабораторная работа: разработка веб-приложения на ASP.NET Core MVC.

## Предметная область
Управление IT-проектами.

## Функциональность
- Список задач (таблица + карточки)
- Подробная информация о задаче
- Добавление задачи с валидацией
- Удаление задачи
- Обработка 404

## Технологии
- ASP.NET Core MVC (.NET 10)
- Bootstrap 5
- Docker
